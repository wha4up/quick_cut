## 核心特性

- **播放即剪辑**  
  无须导入素材或新建工程，直接在播放时标记入点和出点，支持切分、删除、排序及撤销/重做。

- **画面上直接框选裁剪**  
  在播放画面上直接拖动裁剪框，支持常用比例与自定义范围；拖动时实时显示裁剪框与尺寸，裁剪效果在导出时应用。

- **快速复制，需要时重新编码**  
  仅调整起止点时默认采用流复制、不重新编码，通常秒级完成且不损失原始画质；需要滤镜或逐帧精确控制时可切换为重新编码；针对 H.264 源还可开启「消除切点偏移」，让快速复制的入点精准对齐到帧。

- **变速导出，保持音调**  
  安装 FFmpeg 后支持 0.25–4 倍速导出，音频自动补偿音调（变速不变调），导出时长同步缩放。

- **一套界面，多种输出**  
  支持导出视频、提取音频、制作动图（GIF / APNG / WebP）、导出图片序列与拼图，以及提取字幕。支持参数调整与限定目标体积。

- **后台处理与会话记忆**  
  导出任务在后台异步执行，不影响正常播放；按文件自动记忆剪辑进度，再次打开时恢复编辑状态。

- **轻量便携，无侵入**  
  纯 Lua 脚本，无需额外安装庞大剪辑软件。仅依赖 mpv 即可完成基础重编码导出，搭配 FFmpeg / FFprobe 解锁全部高级功能。支持便携配置，离线无遥测，不改动现有配置。

## 适用与不适用

- **适用场景：** 快速截取片段、整理素材、裁剪画面、制作动图、提取音频或字幕，以及无需启动大型剪辑软件的轻量任务。
- **不适用场景：** 多轨精剪、复杂转场、调色、特效、字幕烧录与关键帧动画等成片制作。请使用专业剪辑软件处理。

## 快速开始

### 依赖要求

| 依赖 | 要求 | 说明 |
| :--- | :--- | :--- |
| **mpv** | ≥ 0.38 | 自定义输入框依赖 `mp.input`（0.38.0 起提供）；更低版本脚本仍可加载，但时间码手输等输入框功能会被禁用，参数下拉里的「自定义…」自动隐藏。 |
| **ffmpeg / ffprobe** | ≥ 5.1（可选） | AVIF 封装与 JXL 编码自 5.1 起提供；构建未启用对应库时会自动隐藏格式。**可选组件**：未安装时自动回退为 mpv 内置编码器执行基础导出，差异见下表 |

配置项 `ffmpeg=` / `ffprobe=` 仅写文件名时，按「系统 `PATH` → 脚本目录及其上级（含 `bin\` 子目录）→ 常见安装路径」顺序查找；便携模式下，直接将 `ffmpeg.exe` 放入 mpv 目录或 `portable_config` 即可。

#### 不安装 ffmpeg 时的能力范围

mpv 静态链接了 libavcodec / libavformat，可作为备用编码后端。未安装 FFmpeg 时仍能导出，但仅支持「重新编码」模式：

| 能力 | 有 ffmpeg | 只有 mpv |
| :--- | :---: | :--- |
| 重新编码导出视频（mp4 / mkv / mov / ts / webm） | ✅ | ✅ |
| 音频提取（m4a / mp3 / flac / wav / opus / ogg） | ✅ | ✅ |
| 图片序列（png / jpg / webp） | ✅ | ✅ |
| 动图（gif / webp / apng） | ✅ | ✅ |
| 快速复制（无损、秒级完成） | ✅ | ❌ mpv 无复制编码器，自动转为重新编码 |
| 消除切点偏移 | ✅ | ❌ 依赖 FFmpeg 流复制与 concat 拼接 |
| 合并导出 | ✅ | ❌ 依赖流复制与拼接 |
| 字幕导出 | ✅ | ❌ mpv 不支持导出字幕轨 |
| 图片拼图 / 单帧 | ✅ | ❌ 仅支持序列模式 |
| 限体积两遍编码 | ✅ | ❌ 退化为单遍目标码率，无法严格保证体积 |
| 变速导出 | ✅ | ❌ 内置模式未重写时间戳（详见 [常见问题](docs/faq.md)） |

未安装 FFmpeg 时，上表中不支持的项目在界面上会置灰并说明原因（交互细节见 [常见问题](docs/faq.md)）。

安装 FFmpeg 后脚本会自动优先调用；运行中的 mpv 需重启以重新探测。

### 获取

- **下载发布包**：前往 [Releases](https://github.com/wha4up/quick_cut/releases) 下载最新发布版本。
- **克隆仓库**：通过 `git clone` 获取仓库，使用其中的 `scripts/quick_cut` 目录。

### 安装脚本

将整个 `quick_cut` 文件夹放入 mpv 的 `scripts/` 目录（mpv 会自动加载其中的 `main.lua`）：

- **便携模式**：`<mpv.exe 目录>\portable_config\scripts\quick_cut\`
- **常规模式**：`%APPDATA%\mpv\scripts\quick_cut\`（macOS / Linux 为配置目录下的 `scripts/`）

### 启用剪辑台

可根据界面方案选择以下方式，重启 mpv 并播放视频后即可进入：

- **uosc**：在 `script-opts/uosc.conf` 的 `controls=` 中添加 `button:quick_cut`：

  ```conf
  controls=menu,gap,subtitles,...,button:quick_cut,gap,space,speed,...
  ```

  按钮图标（`cut`）与操作由脚本通过 uosc 接口提供，只需在 `controls=` 中添加即可。

- **mpv 原生 OSC / ModernZ 等**：在 `input.conf` 中绑定快捷键：

  ```conf
  c   script-binding quick_cut/cut_menu
  ```

  等价写法为 `c script-message toggle_studio_mode`。

### 剪辑流程

1. `[` / `]` 标记入点和出点，`ENTER` 加入片段；
2. `e` 打开导出面板，选择类型与参数；
3. 再按 `ENTER` 开始导出。

导出在后台执行、不中断播放；仅改起止点时默认流复制，未安装 FFmpeg 时自动转为重新编码。

### 调整配置（可选）

建议将 `script-opts/quick_cut.conf` 复制到 mpv 的 `script-opts/` 目录后再编辑（避免直接修改脚本目录内的模板）：

- **便携模式**：`<mpv.exe 目录>\portable_config\script-opts\quick_cut.conf`
- **常规模式**：`%APPDATA%\mpv\script-opts\quick_cut.conf`

## 功能详解

### 剪辑操作

剪辑台里整理片段与预览画面。

- **片段整理**：设置入点 / 出点、在播放头切分、删除、排序，或直接输入时间码；`Alt+←/→` 跳到相邻关键帧（标记不吸附到关键帧）。
- **撤销 / 重做**：片段编辑与裁剪共用一条历史（`z` / `y`）；裁剪过程中同样生效，一次拖框记为一步。
- **播放控制**：单段 A-B 循环或多段连播；退出剪辑台后恢复正常播放。
- **波形**：`w` 在时间轴背景画出音频波形（按需扫描，默认关闭）。
- **面板与速查**：`?` 查看当前上下文的快捷键；`h` 折叠按钮面板（时间轴与画面保留，快捷键照常生效）。

### 画面裁剪

- 固定比例（16:9 / 9:16 / 4:3 / 1:1 / 21:9 等）或自定义矩形，导出时生效；
- 拖动时遮罩与尺寸标签实时更新，画面本身不实时裁剪。

### 会话记忆

剪辑进度按文件自动记录到脚本目录下的 `quick_cut_sessions.json`，再次打开同一文件时恢复上次的片段与裁剪状态；`resume_session` 设为 `no` 可关闭。这是脚本自身的状态记录，与导出无关；保存位置与清除方式见 [常见问题](docs/faq.md)。

## 导出功能

导出面板自上而下是四块：**导出类型** → **输出方式** → **编码格式** → **附加处理**，底部另有预设菜单与执行按钮。下面按这个顺序讲。

### 导出类型

| 类型 | 说明 |
| :--- | :--- |
| **视频** | 快速复制或重新编码；音频选「无音频」可导出静音视频 |
| **音频** | 仅导出音频轨：m4a / mp3 / opus / flac / wav / ogg |
| **动图** | GIF / WebP / APNG / AVIF，可设帧率、宽度、循环次数与质量 |
| **图片** | 序列帧 / 关键帧（只解码关键帧，更快）/ 拼图总览 / 单帧（每段一张）；格式 PNG / JPG / WebP / AVIF / JXL / TIFF |
| **字幕** | 仅导出当前选中的字幕轨：SRT / ASS / WebVTT，或 `copy` 流复制（PGS 等图形字幕只能用 `copy`） |

### 输出方式

这一行有两组独立选择：**分片 / 合并**决定产出几个文件，**快速复制 / 重新编码**决定怎么产出。

| 选项 | 含义 |
| :--- | :--- |
| **分片输出** | 每个片段导出为一个独立文件 |
| **合并输出** | 按列表顺序把所有片段合并成一个文件（`m` 直达）；字幕不支持合并，图片仅在「拼图 + 单片段」时可合并 |
| **快速复制** | 视音频流直接复制封装，秒级、无损；入点受关键帧位置限制 |
| **重新编码** | 整片重编码，入点精确到帧，可调全部编码参数 |

需要滤镜、调整编码参数或变速时，模式会自动切到重新编码，此时「快速复制」不可选。

### 编码格式

参数网格，按面板中从左到右、从上到下的顺序：

| 参数 | 作用 |
| :--- | :--- |
| **容器** | mp4 / mkv / mov / webm / ts。换成接受源编码的容器可秒级无损完成，否则自动重新编码 |
| **视频编码** | H.264 / H.265 / VP9 / AV1，含硬件编码器；`copy` 直接复制源视频流 |
| **编码预设** | 编码器的速度档，越快体积越大 |
| **质量模式** | `crf` 恒定质量 / `cq` 恒定量化 / `global_quality` / `bitrate` 固定码率 |
| **质量值** | 随质量模式而变：CRF 值越小画质越高；码率模式则填目标码率 |
| **音频编码** | AAC / MP3 / Opus / FLAC，`copy` 直接复制，「无音频」导出静音视频 |
| **音频码率** | 96k / 128k / 192k / 256k / 320k |
| **像素格式** | yuv420p 兼容性最好；10bit / 4:2:2 / 4:4:4 需要播放端支持 |
| **分辨率** | 原尺寸或指定宽高 |
| **缩放模式** | fit 保比例铺满 / pad 加边 / stretch 拉伸 |
| **帧率** | 原帧率或指定值 |
| **倍速** | 0.25–4 倍；视频时间轴与音频时长同步缩放，音频经 `atempo` 保持原音调。与快速复制互斥，非 1 倍速自动转重新编码 |

视频导出选快速复制时这一整块会收起，只留一句说明——流复制没有编码参数可调。

### 附加处理

导出前异步探测源媒体；探测失败只记日志，不阻塞任务。

| 开关 | 作用 |
| :--- | :--- |
| **快速启动** | 把索引放到文件开头，边下边播更顺；仅 mp4 / mov 出现，不改变画质 |
| **消除切点偏移** | 让快速复制的入点精确到帧，避免吸附到前一关键帧；代价是对起始 GOP 做一次很短的局部重编码再拼接（仅 H.264 源） |
| **自动去隔行** | 检测到隔行源（老录像 / DVD）时自动插入反交错滤镜 |
| **自动去黑边** | 分析片头样本帧执行 `cropdetect`，自动套用黑边裁剪（手动裁剪优先） |
| **音量归一化** | 双遍 `loudnorm` 平准化响度（音频重编码，视频仍可流复制） |
| **去除静音段** | 剔除选区内的静音区间（需要重新编码） |

快速复制下这里只剩「快速启动」与「消除切点偏移」：其余开关都会引入滤镜，而滤镜必须重新编码。

### 编码预设与限定体积

底部左侧的菜单把整组参数一键调到某个取向，两种入口互斥：

- **预设参数** —— 内置「原始」（跟随源文件）、「网页」、「高质量」、「归档」，可在 conf 中自定义（如 NVENC）；也可把当前参数保存为自己的预设。
- **优化目标** —— 画质优先 / 速度优先 / 损失最小 / 限定体积。选「限定体积」后填目标大小（MB，默认 50），脚本按片段**总时长**反算码率（`体积 × 8388.608 ÷ 时长`，扣除约 2% + 0.5 MiB 封装开销）并强制重新编码；目标过小（低于本机该分辨率的下限，最低 16 kbps）、超过源码率或偏离合理范围时会说明原因并预填数值，再按一次 Enter 才继续。

### 输出命名规则

- **默认**：`<源文件名>_<序号>_<起止>_cut`（已命名的片段用自定义名称替换时间码）。
- **自定义模板**：conf 里的 `output_name_template`，支持 `{name}`、`{index}`、`{in}`、`{out}`；只作用于**未命名片段**，生效时不再追加 `_cut`。
- **图片后缀**：单帧加 `_frame`，拼图加 `_sheet`，序列加 `_%04d` 序号（如 `my_video_002_0001.png`）。

## 快捷键速览

| 键 | 动作 | 键 | 动作 |
| :--- | :--- | :--- | :--- |
| `SPACE` | 播放 / 暂停 | `[` / `]` | 标记入点 / 出点 |
| `ENTER` | 添加片段 / 保存编辑 | `s` | 在播放位置切分 |
| `z` / `y` | 撤销 / 重做 | `e` | 打开导出面板 |
| `c` | 打开画面裁剪 | `?` | 查看当前面板快捷键速查 |

所有**键盘快捷键**均可在 `script-opts/quick_cut.conf` 中修改（`key_*` / `crop_key_*`），多个按键以逗号分隔，留空即禁用；剪辑台内鼠标左键由脚本接管（点击画面空白取消选中），滚轮仅在光标位于面板、片段列表或展开下拉菜单时接管，其余时候归 mpv 原生处理（`extra_bindings` 放行的滚轮调音量不受影响）。完整按键说明见[快捷键完整表](docs/shortcuts.md)。

## 界面与个性化配置

脚本界面外观由内置设计规范控制（定义于 `core/ui.lua` 的 `DEFAULT_TOKENS`）；界面图标使用内置字体 `fonts/Quickcut_icons.ttf`，若图标未显示、只剩文字标签，见 [常见问题](docs/faq.md)。

- **外观样式自定义**：在配置文件中通过 `ui_color_*`、`ui_alpha_*`、`ui_radius_*`、`ui_layout_*` 调整颜色、透明度、圆角及几何布局（启动时读取，修改后需重启 mpv）。
- **不可用项样式**：`ui_button_disabled_style` 可选 `strike`（删除线，默认）/ `slash`（斜杠）/ `strike_slash`（两者并用）/ `dim`（仅淡化）；结合 `ui_alpha_button_disabled`（0–1，默认 0.42）与 `ui_layout_button_disabled_strike`（线宽 1–6，默认 2）微调。
- **界面缩放预设**：提供 `ui_preset` 选项，可选 `comfortable` / `compact` / `ultra_compact` / `custom`，适配小屏或浮窗。
- **参数优先级**：`quick_cut.conf` 单项参数 > 显式预设 > 内置默认值。支持命令行临时覆盖，例如 `--script-opts=quick_cut-scale=1.25`。
