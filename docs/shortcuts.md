# 快捷键速查

[返回 README](../README.md)

所有**键盘**快捷键都可在 `script-opts/quick_cut.conf` 中修改（`key_*` / `crop_key_*`）；多个按键以逗号分隔，留空即禁用。鼠标左键与滚轮在剪辑台内由脚本强制接管，不走 conf。进入面板后按 `?` 可查看当前上下文的键位速查。

> 下表只列主键。部分动作另带别名与小键盘等价键（如 `?` / `K`、`ENTER` / `KP_ENTER`、`←` / `KP4`），完整默认值以 `script-opts/quick_cut.conf` 为准。

## 主剪辑台

| 键 | 动作 | 键 | 动作 |
| :--- | :--- | :--- | :--- |
| `SPACE` | 播放 / 暂停 | `[` / `]` | 标记入点 / 出点 |
| `ENTER` | 添加片段 / 保存编辑 | `s` | 在播放位置切分 |
| `DEL` | 删除选中片段 | `x` | 清空（片段 + 标记 + 裁剪） |
| `z` / `y` | 撤销 / 重做（裁剪中同样可用） | `l` | 片段列表 |
| `↑` / `↓` | 上一 / 下一片段 | `t` | 输入片段时间码 |
| `g` | 跳到指定时间码 | `Ctrl+SPACE` | 取消当前选择 |
| `←` / `→` | 后退 / 前进 1 秒（播放中也可用，不暂停） | `Alt+←/→` | 上 / 下一关键帧 |
| `Ctrl+←/→` | 逐帧（会暂停播放；有标记时改为微调标记，并跳到该标记） | `r` | 加入 / 退出播放范围 |
| `e` | 导出 | `m` | 合并导出 |
| `c` | 裁剪（进入裁剪窗口） | `w` | 波形开关 |
| `f` | 保存当前帧 | `h` | 收起 / 展开按钮面板 |
| `?` | 键位速查 | `q` / `ESC` | 关闭剪辑台 |

## 裁剪窗口

| 键 | 动作 | 键 | 动作 |
| :--- | :--- | :--- | :--- |
| `← ↑ ↓ →` | 移动裁剪框 | `Shift+方向` | 快速移动 |
| `-` / `+` | 缩小 / 放大 | `Ctrl+-` / `Ctrl+=` | 快速缩放 |
| `c` | 居中 | `h` | 显示 / 隐藏 HUD |
| `z` / `y` | 撤销 / 重做 | `SPACE` | 播放 / 暂停 |
| `?` | 键位速查 | `ENTER` | 完成 |
| `q` / `ESC` | 取消 | | |

**裁剪窗口的操作条**：

- 固定于画面底部居中，窗口过窄时限制在画面范围内；
- 与裁剪框相交（含完全落入框内）时自动隐藏，避免遮挡画面；
- 按 `h` 手动收起 / 呼出；手动收起与自动隐藏互不影响，收起后不会因相交而重新出现；
- 裁剪编辑期间主面板与时间轴默认隐藏，同样按 `h` 呼出；
- 尺寸标签显示在**窗口上边与裁剪框上边之间并上下等距**，不会被裁剪框或手柄压住。

## 导出确认面板

| 键 | 动作 |
| :--- | :--- |
| `ENTER` | 激活焦点（开始导出 / 确认选项） |
| `TAB` / `SHIFT+TAB` | 下一个 / 上一个焦点 |
| `↑` / `↓` | 调整当前聚焦参数（下拉展开时移动高亮） |
| `BS`（Backspace） | 将当前聚焦参数恢复为**原始参数**的值 |
| `?` | 键位速查 |
| `q` / `ESC` | 先关闭浮层，再按一次关闭面板 |
