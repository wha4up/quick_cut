Modifications

The icons were renamed, geometrically adjusted, re-mapped to the private-use codepoints
starting at U+E900, and compiled into this TTF font file for use by the quick_cut mpv
script. The font's name table keeps the original copyright, the "Material Symbols
subset" description and the Apache License 2.0 reference.
